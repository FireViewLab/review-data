# 크롤러 및 저장 개선

## 네이버 리뷰 미수신

최근7일 네이버 리뷰 실패128건은 리뷰 목록 미수신이며 상품에 양수 리뷰 수가 존재했다. locknlock:13781489400의 기존 코드를 읽기 전용으로 재현한 결과 기존 숫자 포함 탭 선택과 일반 리뷰 경로가 실제 화면의 숫자 없는 리뷰 탭·group-products/query-pages 경로를 놓쳤다.

숫자 없는 리뷰 탭을 우선 선택하고 숫자·괄호 포함 탭도 지원한다. 응답 URL은 쿼리 문자열을 제외한 경로로 비교하며 기존 및 묶음 경로만 허용한다. 묶음 응답은 productNo를 우선하고 없는 경우 originProductNo로 요청 상품과 비교한다. 묶음 응답의 식별값 없는 행은 저장하지 않는다. 작성자 식별값은 기존처럼 저장하지 않는다.

수정 코드를 같은 운영 환경에서 읽기 전용 실행하여 상품 리뷰 수1건·수집1건을 확인했다. 묶음 응답8건 중 요청 상품1건만 반환했다. 검증에서는 DB 저장·AI 요청·Backfill 제어를 하지 않았다. 아직 리뷰 탭 첫 페이지 수집이며 전체 페이지 수집을 구현한 것으로 해석하지 않는다.
