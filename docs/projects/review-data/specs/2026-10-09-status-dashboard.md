# Data 운영 대시보드

## 접속과 인증

- 운영 화면: `https://data.re-view.kr/status` (같은 서버의 `data.beens.kr/status`도 사용 가능).
- 화면 틀만 공개한다. 데이터 API는 기존 Data `INTERNAL_TOKEN` 또는 대시보드 로그인 쿠키가 필요하다. AI 인증 토큰과는 다르다.
- 로그인은 `POST /status/login`, 로그아웃은 `POST /status/logout`이다. 토큰은 브라우저 저장소에 저장하지 않는다. `/status`에만 적용되는 HttpOnly·SameSite=Strict 쿠키를 8시간 발급한다. HTTPS에서는 Secure를 설정한다.
- 쿠키는 기존 수집 API를 인증하지 않는다. 운영 응답은 `Cache-Control: no-store`이다. 로컬에서 내부 토큰 미설정 시 기존 개발 인증 정책과 같이 열려 있다.

## 표시 항목

- 등록 상품, 원본 리뷰 행 수, 과거 이력을 포함한 분석 결과 행 수, 진행 중 수집·분석 작업 수.
- 서버 CPU 사용률(누적 tick 차이), 메모리 사용률(MemAvailable 기준), 1/5/15분 부하. 운영 API에 `/proc`을 `/host/proc`으로 읽기 전용 마운트한다. Docker socket은 마운트하지 않는다.
- 디스크는 API 파일시스템의 용량과 사용량이다. 별도 DB 볼륨·컨테이너별 사용량을 따로 측정한 값은 아니다. 최초 CPU 표본과 Linux proc 정보가 없는 로컬 환경에서는 계산 가능한 자원만 표시한다.
- 최근 15분 신규 저장·저장/갱신·수집 완료·AI claim·AI 완료 처리량. AI claim은 작업 획득 기준 근사치이며 정확한 네트워크 POST 횟수·바이트 계측이 아니다. 재시도에서는 마지막 claim 시각만 남는다.
- 최근 1시간 신규 리뷰 저장 및 분석 완료 리뷰의 5분 구간 그래프. 현재 구간은 진행 중이다.
- 워커와 스케줄러 heartbeat: 10초마다 별도 DB 세션으로 갱신한다. 35초 이상 응답이 없거나 정상 종료하면 오프라인으로 표시한다. 실행 중 작업은 locked_by로 연결한다. idle 워커도 생존 여부를 확인할 수 있다. 실행 중은 작업 성공을 보장하는 의미가 아니다.
- 수집·분석 대기/실행/lease 만료/재시도 소진, 가장 오래된 대기, 독립 발굴 순환 위치·다음 실행·최근 등록/예약/실패.
- 플랫폼별 저장 상품·원본 리뷰, 최신 분석 상태, 리뷰0건 원인, 최신 수집 실패.

## 상세 조회

- 수집/분석 작업은 상품명·상품 ID·플랫폼·상태로 검색한다. 최신 ID부터 cursor로 페이지 이동한다.
- 수집 상세와 상품 리뷰 상세는 **현재 저장된 원본 리뷰**를 보여준다. 특정 수집 작업에서 저장한 건수나 중복 통합된 대표 집합 수와 다를 수 있다. 작업 없는 상품도 직접 리뷰를 조회할 수 있다.
- 분석 상세는 당시 `input_payload`의 리뷰 스냅샷과 `analysis_job_id + review_id`로 대응하는 저장 결과를 나란히 제공한다. 나중에 리뷰 본문이 바뀌어도 전송 당시 내용은 유지한다.
- 전송 표본 수·원본 대표 집합 수·표본 방법·작업 ID·모델/정책·점수·등급·근거를 확인한다. RTI와 각 신호의 null은 계산 불가이며 0으로 바꾸지 않는다.
- AI 결과는 검증 및 DB 트랜잭션 저장 이후 나타난다. 처리 중 SSE 이벤트나 임시 점수를 실시간으로 게시하는 화면은 아니다.
- 상세는 기본50건, 최대100건씩 조회한다. 리뷰 본문은 HTML로 실행하지 않고 문자열로 표시한다. 작성자·raw_payload·원본 오류·인증 헤더 값은 제공하지 않는다.

## 조회 엔드포인트

- `GET /status/api/overview`: 10초 캐시된 운영 집계. 화면도10초 자동 갱신한다.
- `GET /status/api/jobs/{collection|analysis}`: 작업 목록.
- `GET /status/api/jobs/{collection|analysis}/{id}`: 작업과 요청/저장 데이터 상세.
- `GET /status/api/products`: 상품 목록(운영 점검을 위해 리뷰0건도 포함).
- `GET /status/api/products/{platform}/{product_id}/reviews`: 해당 상품 원본 리뷰.

운영 화면은 조회 전용이다. 재수집·재분석·데이터 삭제 버튼은 제공하지 않는다. Spring·프론트와 공용 Product/Review 계약을 변경하지 않는다.
